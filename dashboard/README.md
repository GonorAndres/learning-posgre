# Flight Analytics dashboard

Static Next.js dashboard for route, revenue and fleet analytics. Deployed to
Cloudflare Pages at https://analytics-flights.gonor.me

## Development

```bash
npm ci
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npx next build
```

`next.config.ts` sets `output: "export"`, so the build writes a fully static
site to `out/`. There is no server at runtime: every page is prerendered and
every figure comes from the ten JSON files in `data/`, generated by
`scripts/prepare-data.py` against PostgreSQL.

Because the export is static, `out/` is exactly what gets served. If a page is
missing from `out/` it is missing in production, so CI checks the export
contents rather than trusting a green build.

## Deployment

Pushing to `dev` or `main` runs CI; only a green CI run triggers the Cloudflare
Pages deploy. `main` publishes to production, `dev` to an Access-protected
preview. See `.github/workflows/` in the repository root.
